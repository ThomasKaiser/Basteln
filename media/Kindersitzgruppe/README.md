# Kindersitzgarnitur

Da das vorhandene Ding schon ein wenig wackelig ist und die Enkel ja auch wachsen, Idee aus Holz für (fast) lau einen 110%-115% größeren Ersatz zu bauen, der hoffentlich paar Jahre hält.

Grundidee und Winkel sowie grobe Maße [von hier](https://www.selbst.de/kindersitzgruppe-23322.html) wobei sich die späteren exakten Maße natürlich aus dem vorhandenen Holz ergeben werden.
